## Featured Projects

### PLANNE · Digital Platform for Educational Neuroliderazgo

**Repository:** [PruebaPap-](https://github.com/Axuma322/PruebaPap-)

PLANNE is a web platform designed to support an academic proposal related to neuroeducation, educational leadership, institutional improvement, and evidence-based management.

The platform includes:

- User authentication with Supabase.
- Diagnostic module with initial and final attempts.
- Results by evaluation variables.
- Adaptive training route with stages A, B, C, and D.
- PDF learning materials by module.
- Stage evaluations with retry logic.
- Likert-style self-assessment for institutional improvement.
- Shared forum for institutional evidence and reflection.
- Demo mode for presentations.
- Responsive design for desktop and mobile.

**Tech stack:**  
`HTML` · `CSS` · `JavaScript` · `Supabase Auth` · `Supabase Database` · `GitHub Pages`

This project demonstrates frontend development, authentication, state management, data persistence, educational UX design, and the transformation of an academic concept into a functional digital product.
